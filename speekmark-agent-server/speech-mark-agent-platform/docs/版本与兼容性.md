# 版本与兼容性（本地开发优先）

当前优先适配用户现有环境，暂不要求升级 Go，也不使用 Docker、MySQL 或 Redis。

| 组件 | 当前选择 | 说明 |
|---|---|---|
| Go | 1.23.x | 本地现有版本；go.mod 使用 `go 1.23.0` |
| Gin | 1.11.0 | 避免 Gin 1.12.0 的 Go 1.26 最低版本要求 |
| GORM | 1.31.2 | ORM |
| SQLite 驱动 | 1.6.0 | 本地数据库文件，无需数据库服务 |
| Python | 3.12.x | Agent 运行环境 |
| FastAPI | 0.158.1 | Python API |
| LangChain | 1.2.18 | 按原先指定的 1.2.x 系列 |
| LangGraph | 1.x | 工作流编排 |
| Node.js | 22.x | 前端开发 |
| React | 19.x | 前端 |
| Ant Design | 5.x | UI 组件库 |

## 当前阶段暂不启用

- MySQL：后续有需要再迁移。
- Redis：当前任务状态和记录由 Go + SQLite 处理。
- Docker：本地分别启动三个进程。

依赖是否能在具体机器上安装，仍以本地 `go mod tidy`、`go test ./...` 和前端构建结果为准。
