# 《一屋百年》开发任务清单

- 文档版本：v1.1（2026-11-11）
- 技术环境：Cocos Creator 3.8.8 + TypeScript（正式版）；当前先用 React + Three.js 做 Web 原型验证玩法，代码在 `web/`
- 开发协作：Claude Code + 人工验收
- 当前目标：第一章 10 关

> Web 原型进度：P1–P6 的玩法与 10 关数据已在 `web/` 中实现并通过自动测试，玩法核心在 `web/src/core/`（纯 TypeScript，可迁移到 Cocos）。
> 2026-11-12 优化轮（风险修复 + 市场参照优化）已完成：① e2e 跑通（29 项全过，见 P7）；② 加载失败兜底（`App.tsx` catch + 重试、`main.tsx` ErrorBoundary）；
> ③ 文档对齐（技术架构 v1.1、产品设计补真正产品内容、配置文档 §13 四个开放问题关闭、物件库删 `charger`）；④ 难度拉单调（第 6 关 requiredWrong 1→2、
> 第 7 关 1→2、第 9 关 2→3，埋住比例 0→0.5 单调）；⑤ 遮挡阈值集中配置（`src/core/tuning.ts`，默认 5，实验见 `scripts/occlusion-experiment.ts`）；
> ⑥ 计分与连击（100 分起，每连击 +10%，上限 +50%）；⑦ 限时挑战（选关开关，每关 120 秒）；⑧ 通关整洁 payoff（物品堆淡出 + 整洁度 100%）；
> ⑨ 存档 v2（断点续玩快照 + v1→v2 迁移 + 最高分）；⑩ 房间感底衬（墙面/地板/家具剪影）+ 顶部进度条 + 小物件热区外扩；⑪ 找对星光/飘分、点错抖动、
> 归位格满警告脉冲、提示脉冲加强、音效随连击变调；⑫ MockAdService 补失败/超时分支（默认失败率 0、超时 5 秒）；⑬ 进关预加载进度条。
> 临时美术（网上免费可商用素材替换 emoji 占位）另起一轮，见 `web/ASSETS.md`；正式美术待 Tanaka 提供后替换，文档里不得写成“正式美术已完成”。
> 临时网上素材，待 Tanaka 提供正式美术后替换。
> 常用命令：`npm run dev` 试玩、`npm test` 单元测试、`npm run validate:configs` 配置校验、`npm run e2e` 浏览器端到端测试、

## 5. P2：遮挡系统

### 任务

- 实现物件遮挡关系。
- 实现不可点击状态。
- 实现上层物件移除。
- 实现下层物件解锁。
- 实现多重遮挡。
- 实现遮挡视觉效果（不压暗：全亮显示，点中被压住的物件抖动反馈，解锁时放大脉冲）。

### 验收标准

- 被遮挡物件不能点击。
- 移除一个遮挡物后，仍被其他物件遮挡的物件不能提前解锁。
- 所有遮挡者移除后，物件才能点击。
- 遮挡状态与点击反馈一致（点中被压住的物件抖动提示，不选中下层）。
- 重开关卡后遮挡关系恢复。

### Claude Code 执行提示词

```text
请实现《一屋百年》的物件遮挡系统。

遮挡数据来自关卡 JSON 中的 blocking 字段，含义是“谁挡住我”，不能反过来理解。

要求：
1. 使用独立 OcclusionManager。
2. 不要只依赖 ZIndex 判断遮挡。
3. 支持一个物件被多个物件遮挡。
4. 遮挡物件移除后重新计算状态。
5. 所有遮挡者移除后才能解锁。
6. 被遮挡物件显示统一暗化效果。
7. 重开关卡时恢复初始遮挡状态。

请特别测试多重遮挡和连续移除场景。
```
